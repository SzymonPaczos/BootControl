## Koszyki (pełna wersja — skrót w ROADMAP)

- **CORE (do bety):** GRUB kompletny (config ✅ + **wpisy menu** ❌→do zbudowania + failsafe wiring + rescue), snapshoty/audyt + picker retencji w GUI, GUI v2 (Tor A: A1/A2/A3), CLI jakość (grupa `grub`, `--json`, exit codes, potwierdzenia), raport „Boot environment", daemon idle-exit + poprawka unitu (`WantedBy`, `Type=notify`), packaging deb/rpm/AUR, porządny GitHub, animowana strona (przy becie).
- **KEEP (działa, bez nowej pracy):** systemd-boot (list/default/rename), UKI cmdline, EFI z Linuksa, immutable pre-flight, LUKS keymap guard, Demo Mode, man pages, E2E, threat model.
- **PO BECIE:** TUI = pełna konsola serwerowa (docelowy interfejs adminów — decyzja właściciela), sd-boot/UKI dokończenie (`loader.conf`, reorder/hide/delete, `reinstall_uki`), panel MOK GUI, openSUSE (paczka + kontener), rozważenie Silverblue w macierzy.
- **NA KOŃCU:** Windows (backend `GetFirmwareEnvironmentVariable` + panel + windowsowa detekcja systemów — de facto osobny projekt).
- **DELETE (wykonane commitem, git pamięta):** Paranoia Mode + Strict Mode.
- **IDEA (bez terminu):** Auto-Rescue LUKS/BTRFS wizard, „Gothic 2 mode".

## Zasady w całej kolejce

1. Nic z „po becie" nie blokuje bety ani nie jest reklamowane jako gotowe.
2. Po Etapie 5 każda mutacja w każdym frontendzie ma potwierdzenie + diff (kontrakt).
3. Jedna gałąź = jeden rezultat; TDD bez wyjątków; ratchet po naprawach.
4. Tor B (design, materiał już w claude.ai/design „BootControl GUI Redesign") wraca po pozycji 3.
5. Nowe pomysły w trakcie → backlog (zapis ≠ zgoda), nie do kolejki.
